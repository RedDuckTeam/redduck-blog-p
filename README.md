# redduck-blog

Public blog for RedDuck. TanStack Start (SSR) + Vite + React 19 + Tailwind v4,
deployed to a Cloudflare Worker.

## Scripts

```bash
pnpm dev         # vite dev server on :3000
pnpm build       # production build (regenerates src/routeTree.gen.ts)
pnpm typecheck   # tsc --noEmit
pnpm lint        # oxlint
pnpm test        # vitest run (unit)
```
